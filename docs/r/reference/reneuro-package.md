# reneuro: A European Energy System Model

An open, extensible model of the European energy system built on
'energyRt', with the data, assumptions and processing steps kept
inspectable. The current stage reproduces the core of the open PyPSA-Eur
model and the workflow around it: reading networks, translating them
into 'energyRt' objects, sampling in space and time, solving, and
comparing the result against the source model. Planned extensions cover
alternative datasets, a review of the algorithms that turn raw data into
model parameters, further sectors, and links to other models.
